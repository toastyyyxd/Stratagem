# AGENTS.md — `~/Stratagem`

Half-built game/engine. `src/main.zig` is a stub: it logs `Hello world!` and
imports nothing else, so a passing `zig build` says very little.

Active branch: `dev`.

## Toolchain

- Zig **0.18.0-dev** nightly, from `zig2nix`'s `zig-master` via the flake.
  Never install a Zig version ad hoc; enter the flake (`direnv allow`, or
  `nix develop`). `zls` from the flake is upstream master (BSP-capable) and
  must stay the same compiler generation as `zig`.
- 0.18 changed things this tree relies on: `bitpack struct` (not `packed`),
  `@bitCast` is rejected between `extern struct`s, reflection is
  `field_names`/`field_types`/`field_values`/`decl_names`, optimize modes are
  `.debug/.safe/.fast/.small`, `std.builtin` is an alias for `std.lang`.
- `nix flake update` moves the nightly. Expect source churn when it does; read
  the compiler error and migrate, don't pin an old nightly.

## Commands

```sh
nix develop -c zig build            # install step, builds src/main.zig only
nix develop -c zig build run        # runs the stub
nix develop -c zig build test       # compiles+runs src/tests.zig
nix build .#default                 # packaged binary
nix run .#default
```

`zig build` accepts `-Doptimize=Debug|ReleaseSafe|ReleaseFast|ReleaseSmall`.

## Layout

- `src/`: the live tree (`mem/`, `orca/`, `gpu/`, `io/`, `utils/`).
- `src-old/`: dead legacy code, tracked, not built. Don't port from it blindly.
- `build/`: codegen program for the `zigwin32` dependency, not the app build.
- `.nix-deps/` and `zig-pkg/`: generated by the devshell/build, gitignored.
  Never edit them; they are re-created on shell entry. Sourcing
  `.direnv/flake-profile-*.rc` also re-runs the shell hook, which re-points the
  `.nix-deps` symlinks at the flake inputs — re-link after sourcing if you had
  pointed them somewhere else.

## Dependencies

- `z-wgpu-native` is a sibling repo (`~/z-wgpu-native`), consumed as a flake
  input. Fix bugs there, not in `.nix-deps`. The input is currently
  `git+file://…/z-wgpu-native?ref=migrate/zig-0.18` (TODO: forge URL).
- `zigwin32` bindings are generated by `zigwin32gen` under Zig 0.15.2 and
  retargeted at 0.18 inside the flake's `installPhase`. Change the flake, never
  the generated output.
- `cpu_features` ships no `.pc` and zig resolves `linkSystemLibrary` only
  through pkg-config, so the flake synthesises `cpu_features.pc`. `hwloc` has
  a real one.
- `diffz` comes from `build.zig.zon` (vendored in `zig-pkg/`).

## Verify

- Mechanical change: `nix develop -c zig build` and `zig build test`; report the
  known-red test instead of hiding it.
- Anything touching a module main doesn't import: add a temporary import or a
  test so the compiler actually analyses it — otherwise you're verifying nothing.
- Flake change: `nix build .#default` (ReleaseSafe, full dependency graph) plus
  the devshell build. `nix run .#default` for the binary.
